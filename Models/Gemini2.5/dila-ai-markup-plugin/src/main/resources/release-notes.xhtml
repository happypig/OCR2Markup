Release Notes

v0.5.0

  • AI Markup now runs on the DILA server: The AI Markup action calls the DILA CBRD Parse endpoint (https://cbss.dila.edu.tw/cbrd/parse) instead of an OpenAI-compatible endpoint on your machine. The transformation model and its credentials stay on the server.
  • Preferences simplified: Six OpenAI-era fields are gone (parsing model, detection model, API key, base URL, chat path, AI timeout). Three replace them: CBRD Parse endpoint URL, CBRD Parse token, and CBRD Parse timeout (ms). Enter the shared DILA parse token once to resume work.
  • Clearer preference labels: The Ref-to-Link rows now read CBRD Link Endpoint and CBRD Link timeout (ms) so they are easy to tell apart from the CBRD Parse rows used by AI Markup. Your saved settings and their order are unchanged.
  • Rejected tokens are recognized correctly: A 401 "token rejected" response from the parse service is now reported as a credential problem instead of a connectivity error, even on Java 17, and the troubleshooting export records the cause.
  • No migration of old values: Any OpenAI settings left from a previous version are ignored, never reused, and never sent anywhere.
  • Document language is detected automatically: The request language comes from xml:lang on the document root element, so there is nothing to choose. Regional tags such as zh-Hant and ja-JP are understood; anything else defaults to Chinese.
  • Clearer failures: Each cause the DILA service reports now has its own actionable message, and "cannot reach the service", "no token configured", "token rejected", and "endpoint URL is wrong" are four distinct messages rather than one generic failure.
  • Checks before sending: An empty selection, a selection over 4,000 characters, a missing token, or a malformed endpoint URL are caught locally - no pointless round trip.
  • Timeout: Defaults to 30 seconds, matching the previous AI Markup timeout, because the server performs a model transformation.
  • Interrupted work is discarded: Closing the document or Oxygen mid-request cancels it; nothing is written into a closed document.
  • Unchanged: The review-then-replace workflow, undo history, editor responsiveness, diagnostics export, UTF-8 validation, tag removal, and Ref-to-Link all behave as before.
